- Upstream: https://github.com/sympy/sympy.git, tag **`sympy-1.13.3`**, commit **`b4ce69ad5d40e4e545614b6c76ca9b0be0b98f0b`** (2024-09-18), 1517 .py files under `sympy/`.
- Python venv: `.venv` (uv), sympy editable + pytest + mpmath + hypothesis (sympy's conftest refuses to run without hypothesis).

## Setup (measured: clone + venv + install = 86 s; hypothesis added afterwards in ~5 s)

```bash
git clone --depth 1 --branch sympy-1.13.3 https://github.com/sympy/sympy.git src
uv venv .venv
uv pip install --python .venv/bin/python -e ./src pytest mpmath hypothesis
```

## Layout

- `bugs/<id>/mutation.patch` — `git apply` in `src/` on the clean tag (all 6 pass `git apply --check`)
- `bugs/<id>/ticket.json` — `{"title","body"}`, user voice, no paths/internal names (generated by `make_tickets.py`)
- `bugs/<id>/acceptance.txt` — hidden acceptance: sympy's own pytest node ids, run from `src/`
- `bugs/<id>/snippet.py` — the ticket's snippet, used by validation (do not give to the agent separately; it is already in the ticket)
- `validate.sh [id ...]` — clean: snippet + acceptance; patched: snippet + acceptance; restores the tree. Output: `validation.log`
- `trace_fault.py` — runs a snippet under `sys.setprofile` and prints the real call chain from the public call to the faulty function (cache / multipledispatch wrapper frames dropped)
- `grepcheck.py` — words of each ticket that occur as whole tokens on the faulty (- / +) lines
- `dropped/polys-01` — rejected candidate (see below)

Run acceptance: `cd src && ../.venv/bin/python -m pytest -q -p no:cacheprovider $(cat ../bugs/<id>/acceptance.txt)`

### printing-01 — `__` in a symbol name becomes a subscript
Mutation: `supers.append(part[2:])` → `subs.append(part[2:])` in the `"__"` branch.
Chain: `latex` → `printer.__call__` → `latex` → `LatexPrinter.doprint` → `Printer.doprint` → `Printer._print` → `_print_Symbol` → `_deal_with_super_sub` → `split_super_sub`.
Acceptance: `test_conventions::test_super_sub`, `test_latex::{test_latex_functions,test_latex_issue_4576,test_modifiers,test_issue_12886}`, `pretty/tests/test_pretty::test_upretty_modifiers`.

### simplify-01 — sqrtdenest returns a numerically different value
Mutation: `a1v.append(c*sqrt(s1/g2))` → `sqrt(s1/g)` (wrong one of two similarly named gcds).
Chain: `sqrtdenest` → `_sqrtdenest0` → `_sqrtdenest_rec` → `split_surds`.
Acceptance: `test_sqrtdenest::{test_sqrtdenest_rec,test_issue_6241,test_sqrtdenest3,test_sqrtdenest4}`.
Grep note: the ticket necessarily contains `sqrt`, which is also on the faulty line — but `sqrt` occurs on 10,025 lines of sympy, so it does not locate the fault.

### sets-01 — imageset drops an attained endpoint
Mutation: in the Interval∪Interval handler, `left_open = ((a.start != start or a.left_open) and ...` → `or` (union of two closed-left intervals comes out open-left).
Chain: `imageset` → `set_function` → `handlers/functions._` (Expr, Interval) → `decorators._func` → `Set.__add__` → `Set.union` → `Union.__new__` → `simplify_union` → `handlers/union._` (Interval, Interval).
Acceptance: `test_sets::{test_union,test_image_interval,test_image_piecewise}`.

### matrices-01 — LUsolve returns a non-solution when a row swap is needed past row 0
Mutation: the swap of the already-computed L part of two rows becomes a self-assignment (`a, b = a, b`).
Chain: `Matrix.LUsolve` → `_LUsolve` → `Matrix.LUdecomposition_Simple` → `_LUdecomposition_Simple`.
Acceptance: `test_decompositions::test_LUdecomp`, `test_matrices::test_inverse`, `test_matrixbase::test_inverse` (these hit it through `inv(method='LU')`).

### functions-01 — trig of `x + r*pi` drops the remainder of the pi multiple
Mutation: `return Add(*(rest_terms + [m1*pi])), m2` → `return Add(*rest_terms), m2`.
Chain (the call that produces the wrong value): `integrate` → `Integral.doit` → `Expr._eval_interval` → `_eval_endpoint` → `Basic.subs` → `_subs` → `fallback` → `_subs` → `fallback` → `Application.__new__` → `Function.__new__` → `cos.eval` → `_peeloff_pi`.
Acceptance: `test_trigonometric::{test_tan_expansion,test_cot_expansion}`. (Note: no existing sin/cos test covers a non-half-integer pi remainder; the acceptance tests reach the same line through tan/cot.)

### solvers-01 — polynomial systems: solve → [], nonlinsolve → permuted tuples
Mutation: `solutions.append(solution + (zero,))` → `(zero,) + solution` (back-substituted values come out in reversed generator order).
Chain: `solve` → `_solve_system` → `solve_poly_system` → `solve_generic` → `_solve_reduced_system` (recursive). `solve` then checks the wrongly-ordered tuples, rejects them all and returns `[]`; `nonlinsolve` returns them unchecked.
Acceptance: `test_polysys::{test_solve_poly_system,test_solve_generic}`, `test_solveset::{test_nonlinsolve_inexact,test_nonlinsolve_issue_25182}`.

## Grep check (`grepcheck.py`)

Ticket words (>= 3 chars) that also occur as tokens on the faulty lines: functions-01 none, matrices-01 none, printing-01 none, sets-01 `and` only, simplify-01 `sqrt` only (see above), solvers-01 none (ticket deliberately avoids the word "solutions").

## Dropped

- **polys-01** (`dropped/polys-01/mutation.patch`): `polys/densetools.py dup_sign_variations` no longer skips zero coefficients (`if coeff: prev = coeff` → `prev = coeff`); symptom `real_roots(x**3 - 2*x)` → `[0]`. Rejected because the mutation makes root isolation **loop forever** on some inputs: `test_rootoftools.py` hangs (killed after 120 s; a broader run hung > 3 min). An agent running nearby tests would stall, confounding the study's time/cost measure.
- Considered and not used: Interval∩Interval (symptom `Interval.intersect` greps straight to the handler); `dup_mirror` off-by-one (computes `-f(-x)`, same roots, no symptom); several `polysys` mutations that only raise `NotImplementedError`, after which `solve` silently falls back to another method and returns the right answer.
