# Benchmark: packs as a tool the agent asks for (lean-pack), 2026-11-15

The registry results measured a pack **placed in the agent's prompt** by the harness. In real use the agent has to ask
for it. This run adds the arm that measures that: `lean-pack`, the seven lean MCP tools plus a `pack` tool that returns
the same pack text in one call. Exploratory, not pre-registered.

## Setup

- **Repositories**: lnbits and Netflix Dispatch, at their pinned commits, the task sets generated by today's code
  (12 and 8 tasks; every pack scored 1.0 against the truth, and the independent truth check found no missing caller).
- **Arms**: `plain` (search and read), `lean` (7 tools), `lean-pack` (7 tools + `pack`, with the `devkb-lean-pack`
  instructions as they were at the time: ask for the pack first), `pack` (the pack in the prompt).
- **Protocol**: Sonnet in every arm, 5 repetitions, every arm of a repository in one shuffled session, 40-turn cap.
  400 runs, 1 invalid (Dispatch), $23.68. Every tool-arm run connected to the graph server.

## Results

Both repositories pooled (`report-both.json`): cost saved against plain, quality difference, 95% bootstrap intervals.

| Arm | Median cost per task | Saving | Quality | Quality gain | Turns |
|---|---|---|---|---|---|
| plain | $0.093 | — | 0.937 | — | 9 |
| lean (7 tools) | $0.045 | 42% [35, 48] | 0.975 | +0.037 [+0.021, +0.054] | 6 |
| **lean-pack** | **$0.032** | **53% [45, 59]** | **0.994** | **+0.057** [+0.043, +0.071] | 4 |
| pack (in the prompt) | $0.027 | 58% [51, 64] | 0.980 | +0.042 [+0.027, +0.058] | 3 |

By repository:

| Repository | lean | lean-pack | pack |
|---|---|---|---|
| lnbits (12 tasks) | 45% / +0.023 | 57% [48, 65] / +0.036 | 65% / +0.035 |
| Dispatch (8 tasks) | 36% / +0.059 | 46% [33, 56] / +0.088 | 46% / +0.053 |

By task kind (pooled):

| Task kind | lean | lean-pack | pack |
|---|---|---|---|
| impact on route handlers (8) | 50% / +0.080 | **70%** / +0.110 | 64% / +0.079 |
| error to route handler (5) | 56% / −0.004 | **68%** / +0.025 | 71% / +0.024 |

## Reading

- **Agents ask for the pack**: every one of the 100 lean-pack runs called `pack`.
- **On chains, asking for the pack is as good as being handed it**, and the quality is the highest of any arm: 70% on
  impact tasks (the in-prompt pack 64%), 68% on error traces (71%).
- **On one-hop questions it costs more than plain search** (−53%): the pack call is an extra step where one grep
  answers, and agents re-checked packs with `callers` (26 of the 100 runs called it, 36 calls in all). The instructions now
  say to search for one-hop lookups and not to re-check a complete pack (PR #23); that change is **not** measured here.
- **The default is now `lean-pack`** (`devkb init`, `devkb mcp`): overall 53% cheaper than plain and 11 points ahead of
  the 7-tool set alone, with the highest quality.
- **Limits**: two repositories, 20 tasks, one model; the instructions used in the run were the earlier version.

## Reproduce

```bash
for r in lnbits dispatch; do
  .venv/bin/python -m devkb.bench.pipeline prepare $r
  .venv/bin/python -m devkb.bench.pipeline run $r --arms plain,lean,lean-pack,pack --reps 5 --model sonnet
  .venv/bin/python -m devkb.bench.pipeline report $r --model sonnet
done
```

Run from devkb at commit `77f6986` (the merge that added the `pack` tool).
